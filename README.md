# 针经堂 · 针灸自学网站

纯静态、零依赖、双击即开的个人中医针灸学习站。以《灵枢》为经、以腧穴为纬，
零基础起步：理论课 → 经络穴位 → 经典诵读 → 自测复习 → 医案对账。

## 打开方式

- **本地**：双击 `index.html` 即可，无需安装任何东西。
- **在线**：GitHub Pages 挂载后浏览器直达（HTTPS 还能解锁手机端摄像头扫码导入）。

## 功能

| 板块 | 内容 |
|---|---|
| 理论 | 6 门课：经络总论、腧穴总论、特定穴纲要、刺法灸法安全、自我保健实操、配穴方法与治疗总则 |
| 经络穴位 | 十四经 + 经外奇穴；Wellcome 藏古籍木刻经络图（CC BY 4.0）；235 个精讲穴，361 穴全速查 |
| 经典诵读 | 《灵枢》15 篇 + 《难经》9 难，AI 参考译文如实标注，注家分歧笺注卡、有出处医案对账 |
| 习练 | SRS 间隔复习自测、对比卡组（易混穴）、循经点穴（按流注顺序回忆） |
| 医案 | 散在条文下的真实医案汇总，篇章筛选 + 关键词搜索 |
| 记录 | 已读打卡绿墙、朱批笔记、全文搜索；数据存 localStorage，支持文件导出/导入与二维码接力 |

## 数据与内容

- 学习数据只存在**本机浏览器** localStorage，不经过任何服务器；换设备用「备份」页导出导入。
- 经典原文供诵读学习；**译文与注解为 AI 参考，仅供参考**，注家分歧并列呈现、医案均注明出处，最终以原典与师授为准。
- 本站不构成医疗建议；针刺实操须正规面授师承，持续病症请就医。

## 改内容

内容与代码分离：改 `data/*.js`（schema 见 `data/SCHEMA.md`），保存刷新即生效；
改完跑 `node tools/check_data.js` 校验。开发历程见《工作进度与下一步.md》。
